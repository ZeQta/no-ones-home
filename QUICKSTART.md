# Quick Start Guide - Fears to Fiction

## 🚀 Getting Started in 3 Minutes

### Step 1: Start a Local Server

**Option A - Python (if installed):**
```bash
cd /workspace
python -m http.server 8000
```

**Option B - Node.js (if installed):**
```bash
cd /workspace
npx http-server -p 8000
```

**Option C - VS Code:**
- Install "Live Server" extension
- Right-click `index.html`
- Select "Open with Live Server"

### Step 2: Open in Browser

Navigate to:
```
http://localhost:8000
```

### Step 3: Start Playing!

1. Click **"START EPISODE"** on the main menu
2. Wait for loading (a few seconds)
3. Read the phone message when it appears
4. Use **WASD** to move, **Mouse** to look around
5. Press **E** to interact with objects
6. Enjoy the horror experience!

## 🎮 Tips for Best Experience

### Before Playing
- ✅ Use **headphones** (critical for immersion!)
- ✅ Play in a **dark room** if possible
- ✅ Ensure your browser supports **WebGL 2.0**
- ✅ Close other tabs for best performance

### During Gameplay
- 🔍 **Explore thoroughly** - look at everything
- 👂 **Listen carefully** - audio cues are important
- 🚪 **Try interacting** with objects (press E)
- 📱 **Press P** to open your phone anytime
- ⏸️ **Press ESC** to pause

### If You Get Stuck
- Check the **objective hint** (top-left)
- Listen for **audio cues** pointing you in the right direction
- Try **exploring different rooms**
- Look for **interactable objects** (furniture, doors, etc.)

## 🐛 Troubleshooting

### Black Screen
- **Cause:** WebGL not supported or browser issue
- **Fix:** Try Chrome/Edge, update graphics drivers

### No Sound
- **Cause:** Browser audio policy (user interaction required)
- **Fix:** Click anywhere on page to enable audio

### Laggy Performance
- **Cause:** GPU not keeping up
- **Fix:** Lower quality settings, close other tabs

### Mouse Not Locked
- **Cause:** Pointer lock not activated
- **Fix:** Click on the screen to lock mouse

### Game Won't Load
- **Cause:** Module import error
- **Fix:** Must use local server (not file:// protocol)
