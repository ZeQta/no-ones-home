STEP 1: Start the server
-------------------------
Open terminal and run ONE of these:

    python3 -m http.server 8000          (Recommended)
    python -m SimpleHTTPServer 8000      (Python 2)
    npx http-server -p 8000              (Node.js)
    ./start-server.sh                    (Linux/Mac script)
    start-server.bat                     (Windows script)

================================================================================
❓ TROUBLESHOOTING
================================================================================

Problem: Page won't load
Solution: Make sure you're using http://localhost:8000 (not file://)

Problem: Black screen
Solution: 
  1. Press F12 to open console
  2. Look for error messages
  3. Try test.html first

Problem: Can't move
Solution: 
  1. CLICK ON THE SCREEN (this locks the pointer)
  2. Then WASD/Mouse will work
  3. You should see cursor disappear

Problem: "Module not found"
Solution:
  1. Server must be running
  2. Use http://localhost:8000
  3. Try Chrome or Firefox
